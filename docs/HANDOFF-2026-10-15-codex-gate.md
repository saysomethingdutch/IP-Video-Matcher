# 交接：Codex 正式担任 Owner/Gate（2026-10-15）

写给 Codex。2026-10-03 起你临时担任 Gate（D-085），所有者 10-15 决定改为正式担任（D-092）。Claude 不再日常当 Gate，改为在关键节点做独立审计（见第 3 节）。

这份文档取代 `docs/HANDOFF-2026-10-03-codex-gate.md`。旧文档里的现状、规矩、验收清单、关键位置仍然有效，本文只写变化和新活怎么开工。

先读：本文 → `AGENTS.md` → `docs/HANDOFF-2026-10-03-codex-gate.md` 第 4–6 节 → `docs/workorders/DECISIONS.md` 末尾的"工单状态" → `docs/LESSONS-tsxk.md`。

## 1. 你当临时 Gate 时做得好的，继续保持

- **守边界**：加阿里百炼之前先问所有者（D-088）；上传范围逐段核对；不碰 key。
- **留痕**：每一步都记决定，提交编号、调用次数、账单出处都写清楚。
- **不把估算当事实**：账单没出齐就写"实际金额未知"（D-090、D-091）。
- **不自己验收自己写的代码**：实验代码交给另一个会话写，你来验。

## 2. 要注意的地方

1. **给所有者的话要短。** 所有者是律师，不是工程师。WO-110 的结果说明里，数字和术语堆得太密。
   - 给所有者的回复：先一句结论，再三五行要点，最后一个推荐，加可以直接粘贴的提示词；
   - 细节放进交付说明和 `DECISIONS.md`，不要贴进对话。
2. **验收要读输出。** 抽几份全文像核验人一样读，不要只看分数。吞噬星空第一版就是只看各列准确率放行的，结果漏了大量废话（D-077）。
3. **开发和验收要分开。** 开发交给另开的 Codex 会话（用它自己的工作树），或交给 Claude Code。你自己动手的部分，交付说明写明"自验"。
4. **只把所有者才能定的事拿去问所有者。** 这类事包括：数据上传的授权、花钱、客户口径、要不要接进流程。技术选择你自己定，事后在决定里写理由。

## 3. Claude 的新位置：关键节点的独立审计

Claude 的用量有限，只在这几个节点上请它看一眼。由所有者说一句"让 Claude 审一下 WO-xxx"即可：

- 新案子摸底和所有者试核 20 行之后、全量跑之前；
- 导出最终工作簿交给团队之前；
- 改变数据上传范围或模型服务商之前；
- 你和执行者对验收结论有分歧时。

请 Claude 审计时，给它工单、交付说明、相关提交编号和产物位置。不要让它从头读对话。

## 4. 新活怎么开工

所有者说"来新活了"。具体是什么案子，等所有者说。开工按这个顺序：

1. **先问清楚四件事**，一次问完：
   - 客户和作品是什么；
   - 比对表在哪、哪个 sheet、哪些行、要填哪些列；
   - 证据是什么形式（公证处现场录像、平台录屏，还是别的），在哪；
   - 客户的比对要求或指引文件在哪，截止时间是什么。
2. **照 `AGENTS.md` 的"新案子怎么开始"做**，尤其是：
   - 抽约 20 条证据摸底，遇到新的证据形式就补模块，不要硬套；
   - 用客户的要求文件写规则文件，请所有者确认口径；
   - **先让所有者核 20 行，再全量跑**（D-077）；
   - 所有者核过的行就是标准答案，之后每次改规则都先在这些行上试（D-078）。
3. **吞噬星空留下的做法直接用**：
   - 时间线修正、视频说明过滤、【其他】只放程序填写的事实；
   - 模型分不准的类别，备两版让所有者一键切换；
   - 核对页显示依据；
   - "Owner 代办"的批量修改走清单，所有者确认才写入；
   - 回归检验。
   - 复盘第 8 节里还没做的几项，看新案子用不用得上，再决定排不排。
4. **授权要重新确认**：
   - 吞噬星空的画面上云授权（D-057 ③）不自动延伸到新案子；
   - 音频默认不上传。WO-110 的云端转写更准，一个项目约两块钱。要不要在新案子里用，问所有者；如果是公证处现场录像，不建议用。
5. **案件配置和数据位置**写进新的 `cases/<案件>.yaml`。客户材料只读，不进 git。

## 5. 收尾的约定

- 每个工单交付后：验收结论记进 `DECISIONS.md`，更新"工单状态"。确认没有客户文件后，用 `tools/publish_github.sh --yes` 同步到 GitHub。
- 项目收尾时：写一份复盘（参照 `docs/LESSONS-tsxk.md`），打标签，提醒所有者处理录屏等大文件。删除由所有者自己执行。
