- JSON 新增 `other_pages`：每段记 BV、起止录屏秒、是否带自动连播标记。

## 2. R：量进度条

- B 站播放器底部始终有一条细进度条，蓝色是已播放的部分。在目标页面区间内每 2 秒量一次：蓝色长度占整条的比例。
- **判"是"**：
  - 从 0 附近开始，一路走到 99% 以上，中间没有明显的向前跳跃；
  - 中途卡住、从头重播，都不影响；
  - 播完后自动连播，是"播完了"的旁证。
- **判"否"**：
  - 进度条向前跳，即跳转；
  - 目标页面结束时进度还没走到头，即中途退出。
- **实现要求**：
  - 进度条的位置要自己找，不要写死坐标；
  - 控制栏弹出、页面滚动时要能处理；
  - 量不出来的，仍标黄。
- 按 1 倍速估算视频时长，记进 `duration`，并注明"进度条估算"。
- Owner 在 7857、7986 两条上试过，读数稳定（D-060）。
- **验证**：
  - 示例 13–17；
  - 已有 73 行靠悬停读数判出了 R，拿来和新办法对照，报告一致率。
