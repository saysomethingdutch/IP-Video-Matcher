## 0. 边界

- **只做实验**：不改生产流程、案件配置、`workspace/tsxk/rows/`，不写正式核验存储，不 push。
- **本机模型**：所有者已同意下载，下载前在交付说明里写明实际大小：
  - `ollama pull gemma4:26b`，约 18 GB；
  - `ollama pull gemma4:e4b`，约 9.6 GB。
  - 本机是 M3、24 GB 内存，硬盘剩约 34 GB。26B 会占大部分内存，跑的时候不要同时跑别的大任务。
- **AI Studio**：模型 `gemma-4-31b-it`。
  - key 由所有者自己申请，写进 `~/.zshrc`，变量名 `GEMINI_API_KEY`。你不读、不打印、不复制 key，调用一律用 `zsh -lic '…'`。

  - 免费档的限额以所有者控制台为准（第三方说法是每分钟 15 次、每天 1,500 次）。要节流；遇到 429 就等，不要换账号绕过。
- **数据**：
  - 发给 AI Studio 的只有：播放器区域的截图，和给模型的事实文字。
  - **音频一律不出本机**。

- **AI Studio**：Gemini API 的 OpenAI 兼容接口 `https://generativelanguage.googleapis.com/v1beta/openai/`。

图片用 base64 传。每次调用都记下：耗时、token 数、错误。
