# WO-103 吞噬星空：声音这一路

- 签发：Owner　执行：**Codex**（做完 WO-101 之后）　时间盒：**半天**
- 分支：从 `main` 切出 `tsxk/wo-103-audio`
- 交付说明：`docs/workorders/WO-103-RESULT.md`，不超过半页

## 目的

U（是否解说）、V（是否仅增加背景音乐）、Z（合理使用可能性）都要靠声音判断。

WO-102 在示例录屏上已经看到后果：没有声音，13 号是重新配音的视频，机器却判了"低"；V 只好一律标黄。

## 做法

1. **复用 `pilot/audio`**：本地 SenseVoice-Small，不上传音频（D-019、D-043、D-047）。只处理网页台账给出的播放区间。
2. **每行输出 `<case>/audio/<row>.json`**，字段沿用七时吉祥的接口：
   - 转写文本和时间戳；
   - UP 主口播（过滤后的）；
   - 说话占比、BGM 占比；
   - 疑似 UP 主配乐：是 / 否 / 无旁证。
3. **这个案子怎么定"原剧对白"**：吞噬星空没有原剧台词索引，改为对照同时刻画面上的字幕。
   - 原片自带字幕，转写和字幕对得上的，算原片对白。
   - 对不上、又有持续人声的，算口播候选。
   - "疑似 UP 主配乐"的旁证：歌词字幕、B 站音乐标签、长时间只有音乐。
4. **验证**：用示例 13–17 号，写出每条的口播和配乐判断，交 Owner 抽查。13 号是重新配音的，应当检出口播。
