## 3. 提示词的修正（B、C 两类和备用版都用）

1. **去掉**"看不出哪句是 UP 主自己的，按单IP混剪判"。
2. **解说**改为正面写：
   - **算 UP 主的讲述或点评**：
     - 用第三人称交代前因后果，例如"罗峰因为偷取…被传送到…"；
     - 介绍背景设定，例如"这匠神之主本是宇宙尊者，后来…"；
     - 分析评价，例如"此事绝非简单…必然另有深意"；
     - 吐槽、玩梗的字幕；
     - 向观众提问。
   - **算原片台词**：
     - 角色之间的对话、用"我""你"对着某人说的话；
     - 角色自述或转述，例如"老师说…"；
     - 和这些对白混在一起的叙述。
   - UP 主的讲述或点评有两句以上、贯穿视频的，归解说类。只有标题和零星几句的，按 `quote_captions` 口径归单IP混剪。

4. **V 的校验恢复到 WO-107 之前**：人声转写里有句子（歌词除外），或者 U 为"是"时，V 不能为"是"。

   - 解说以剧情复述为主的填中；
