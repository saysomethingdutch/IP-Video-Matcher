## 1. 修改

1. **默认不引用原话**
   - 用概括转述写 UP 主的观点和情绪，例如"吐槽男主理解能力差"，不写"他说'……'"。
   - 只有特别精炼、有代表性的一句，才允许引用，最多 1 处，并且不加粗。
   - 校验器相应调整：引号最多 1 处。证据引用继续保存在 JSON 里，只是不写进正文。
2. **第一段写实，不堆砌**
   - 写清楚这条视频围绕哪段剧情或哪个主题；
   - 写 1–2 个 UP 主的具体观点或处理手法，用转述；
   - 总字数目标不变（220–300 字）。
3. **标题自称 reaction，且有边看边评的点评**（字幕、口播或出镜），类型判 reaction，不判夹叙夹议。这条写进 `rules_qsjx.yaml`，注明依据。
