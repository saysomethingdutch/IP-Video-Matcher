## 1. 按行批准，用键盘操作

- 每行加一个按钮"本行其余全部批准"：把这一行还没核验的列，一次按当前值批准。已修改过的列不受影响。
- 再加一个"批准并到下一行"。
- 快捷键：
  - 上一行 / 下一行；
  - 本行其余全部批准；
  - 跳到下一个有标红或重点标黄的行。
  - 快捷键在页面上写明。输入框里打字时，快捷键不生效。
- 核验人填一次就记住，不用每次都填。

## 2. 提示分级，减少干扰

现在有 261 行标黄、3,023 个格子上色，重点被淹没了。分两级：

- **重点**（给格子上色）：
  - 标红；
  - Z=高；
  - Q=是；
  - 偷渡；
  - R 待核；
  - 画面复核后仍待定；
  - 下面第 3 条的审计线索。
- **提示**（折叠显示，不上色）：
  - 争议帧复核后已经采用或不采用的；
  - 播放器位置一类技术说明。

分级规则写成一张表，放进交付说明，Owner 会逐条过目。

- **没核验的格子**：保持现在的做法，按机器的提示上色、加批注。
