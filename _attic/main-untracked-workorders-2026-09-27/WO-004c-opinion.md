## 0. 目标

给"合理使用可能性 = 是"的每一行起草比对意见。格式和口径**完全按客户要求**，其他行填固定值。

意见里的**每个事实都要能在 RowDigest 里找到出处**，由代码校验。客户要求里明确说"慎用 AI 撰写比对意见"，表意不清、与视频脱节、语句重复的会被扣钱。所以宁可短而准，不要长而空。

## 1. 什么时候写

| 情况 | 比对意见 |
|---|---|
| 合理使用可能性 = 否 | `/`，不调用模型 |
| 重复取证的非主行（WO-004b 已标） | `同序号XXXX，重复取证` |
| 疑似故意跳播（红标） | **不起草**。在核对页给出客户要求原文的固定文字作为候选，由所有者决定 |
| 分类为"不确定" | 照常起草，标黄 |
| 合理使用可能性 = 是 | 起草，见 §2–§4 |

## 2. 固定格式（客户要求原文）

三段加一句结论。**段首提示语不能省**：

```
【使用的性质和目的】……具有转换性。
【使用的比例】……构成适当引用。
【对原作品的替代可能性】……
因此该视频构成"介绍、评论、说明"目的的合理使用。
```

- 全文以 200–300 字为宜，校验上限 380 字。
- 体现转换性的关键句用 `**…**` 标出，只标 1–2 处。导出 Excel 时转成加粗，由 WO-005 负责。

## 3. 三段分别怎么来

### 3.1 【使用的比例】：代码按模板生成，模型不碰数字

**取值来源**

| 项目 | 来源 |
|---|---|
| 对应剧集 | 取 content 结论里有台词证据的集数。没有证据时用原告声称的集数，并标黄。 |
| 每集时长 | 用本地原剧 `real_test/qsjx_epNN.ts` 实测（ffprobe）。缺集时用本地各集的平均值，写"每集平均长约 X 分钟"。 |
| 引用画面时长 | v1 用视频时长。人工样例就是这么算的。 |

**比例** = 引用画面时长 ÷（集数 × 每集时长）：
- ≤ 10% 时，写"占原作品比例较少，为 X%"。
- \> 10% 时，只写"占原作品比例较少"，不写数值。这是客户要求第 4 条。

**模板**（来自人工样例）：
- 视频时长已知：
  > 对应剧集为第{集}集，{每集时长}，被诉视频引用原作品的画面仅{m分s秒}，占原作品比例较少，为{x}%，足以构成适当引用。
- 视频时长为"未知"：
  > 对应剧集为第{集}集，约长{X}分钟，占原作品比例较少，足以构成适当引用。

### 3.2 【使用的性质和目的】：模型起草，必须具体

**输入**：只给文字，并且去标识化。
- 性质和子类、四格
- UP 主文字：非原剧字幕加语音转写，按时间排序、去重，截到约 1,500 字
- 画面事实：出镜、布局、其他作品、背景音乐线索
- 视频标题、对应集数、是否跳播

**写法**：
- 至少写出一个**这条视频特有的**点：UP 主的具体评论或观点、混剪的情感主题、配乐或字幕的作用。只写"对剧情进行了评论"这类话，不合格。
- 每个具体点都要在 JSON 里附一条证据引用。引用必须逐字出现在 UP 主文字或画面事实里。意见正文不必引用原话，客户要求"尽量概括而少引用"。
- 外语语音（泰配 reaction）不引用原话，只概括反应的类型，比如惊呼、大笑、评论角色。概括要有转写或画面事实作依据，并标黄"外语转写，请核对大意"。
- 结尾写"具有转换性"或"具有一定的转化性使用特征"。

### 3.3 【对原作品的替代可能性】：模型按类型写，一两句

从客户的三个示例里取角度：
- **reaction**：观众为了陪伴感和解读视角而看；反而起到宣传推广作用。
- **混剪**：未再现原作品情节，只剪辑了零散画面；观众看的是作者视角的观感体验。
- **解说**（夹叙夹议、观点评析）：观众为了了解 UP 主的观点而看。

视频时长小于 5 分钟的，可以加上"时长较短"。

### 3.4 结论句

固定写"因此该视频构成"介绍、评论、说明"目的的合理使用。"

## 5. 校验器（代码实现，必须全部通过）

1. **结构**：三段提示语按顺序出现，结论句固定，字数 150–380（不计 `**`）。
2. **数字**：正文里的每个数字，包括集数、分秒、百分比、分钟，都必须等于 RowDigest 或 §3.1 的计算值。
3. **引号**：引号里的文字必须逐字出现在 UP 主文字里。例外是客户示例用语，如"介绍、评论、说明""嗑CP""获得陪伴感""学习解读视角"。
4. **作品名**：除《七时吉祥》外，出现的任何《…》都必须能在画面事实或 UP 主文字里找到。
5. **禁用语**，来自客户列的"常见错误"：
   - "只在B站传播"
   - "并没有完全或主要以他人作品代替自己的创作"
   - "没有单纯介绍原作品剧情"，应改为"未再现原作品情节"
   - "筛选性"
   - 把"播放"当成 UP 主的动作
   - "一口气看完"，除非标题里有
6. **具体性**：【使用的性质和目的】里至少有一处与 UP 主文字或画面事实连续重合 ≥ 4 个字，标题除外。否则判为"套话"。
7. **加粗**：1–2 处 `**…**`，只能在第一段。

**不通过时**：带着错误清单重试一次。仍不通过的，保留草稿，标红"意见未通过校验"，并写明原因。
